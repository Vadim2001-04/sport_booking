# СпортБронь — система бронирования спортивных площадок (MVP)

Веб-приложение на Python/Flask: пользователь находит спортивную площадку, выбирает дату и свободный часовой слот и бронирует его. Владелец (администратор) управляет площадками и видит все брони.

## Возможности MVP

**Пользователь**
- каталог площадок с фильтром по виду спорта;
- карточка площадки: описание, цена, календарь на 14 дней вперёд, сетка часовых слотов (свободно / занято / прошло);
- регистрация, вход, выход;
- бронирование слота в один клик (с подтверждением);
- «Мои брони»: история, статусы, отмена будущей брони.

**Администратор**
- список площадок, добавление и редактирование (название, вид спорта, адрес, описание, цена за час, часы работы);
- скрытие площадки из каталога без удаления;
- все брони с фильтрами по площадке и статусу, сумма активных броней;
- отмена любой брони.

**Бизнес-правила**
- нельзя забронировать занятый слот (проверка уникальным индексом в БД — защищает и от одновременных запросов);
- нельзя бронировать время в прошлом, вне часов работы площадки и дальше чем на 14 дней;
- пользователь отменяет только свои и только ещё не начавшиеся брони;
- цена фиксируется в брони на момент бронирования (изменение цены площадки не меняет старые брони).

## Запуск

Нужен Python 3.10+.

```bash
cd sport_booking
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS / Linux:
source venv/bin/activate

pip install -r requirements.txt
python app.py
```

Открыть в браузере: http://127.0.0.1:5000

При первом запуске создаётся файл `booking.db` с четырьмя тестовыми площадками и администратором:

| Роль | Email | Пароль |
|---|---|---|
| Администратор | admin@example.com | admin123 |

Обычного пользователя создайте через «Регистрация». Чтобы начать с чистыми данными — остановите приложение и удалите `booking.db`.

```

│   └── style.css       # оформление
└── templates/          # HTML-шаблоны Jinja2
    ├── base.html       # общий каркас: шапка, меню, уведомления
    ├── index.html      # каталог площадок
    ├── venue.html      # площадка: выбор даты и слота
    ├── my_bookings.html
    ├── login.html, register.html, error.html
    └── admin/          # админ-панель: площадки, форма площадки, все брони
```

## Модель данных

- **users** — пользователи: имя, email (уникальный), хеш пароля, признак администратора.
- **venues** — площадки: название, вид спорта, адрес, описание, цена за час, часы работы, активна ли.
- **bookings** — брони: пользователь, площадка, дата, час начала слота, цена, статус (`active` / `cancelled`).

Слот = один час: бронь с `hour = 18` означает 18:00–19:00.

## Маршруты

| Метод | URL | Что делает |
|---|---|---|
| GET | `/` | каталог, `?sport=` — фильтр |
| GET | `/venue/<id>?date=YYYY-MM-DD` | площадка и слоты на дату |
| POST | `/venue/<id>/book` | забронировать слот |
| GET | `/my-bookings` | мои брони |
| POST | `/booking/<id>/cancel` | отменить бронь |
| GET/POST | `/register`, `/login` | регистрация, вход |
| GET | `/logout` | выход |
| GET | `/admin/venues` | админка: площадки |
| GET/POST | `/admin/venues/new`, `/admin/venues/<id>/edit` | добавить / изменить площадку |
| GET | `/admin/bookings?venue_id=&status=` | админка: все брони |
